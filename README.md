# AI勉強会告知ページ

このリポジトリには、社内AI勉強会の告知ページ (`index.html`) が含まれています。

## プレビュー方法

### 1. ブラウザで直接開く
1. このリポジトリをローカル環境にクローンまたはダウンロードします。
2. `index.html` をダブルクリックするか、お好みのブラウザで開きます。

### 2. 簡易Webサーバーを使う
ローカルでHTTPサーバーを立ち上げたい場合は、以下のコマンドを使ってください。

```bash
python3 -m http.server 8000
```

コマンドを実行後、ブラウザで `http://localhost:8000/index.html` にアクセスするとプレビューできます。

※ VS Codeなどのエディタをお使いの場合、Live Server拡張機能でもプレビューできます。
